format

参数名 描述 可否为空
date/long 要格式化的时间，date类型或时间戳 否
pattern 格式化格式，默认yyyy-MM-dd HH:mm:ss 是

返回值类型：String

格式化时间

  • 获取当前时间的yyyy-MM-dd格式

    ${date.format(date.now(),'yyyy-MM-dd')}

parse

参数名 描述 可否为空
string 要转换的时间，String类型 否
patterns 日期格式,可写多个 否
参数名 描述 可否为空
long 否

返回值类型：Date

日期转换

  • 获取当前时间的yyyy-MM-dd格式

    ${date.parse('2008-08-08','yyyy-MM-dd')}

  • 根据时间戳转成Date类型

    ${date.parse(1218124800000)}

now

获取当前时间

返回值类型：Date

  • 获取当前时间

    ${date.now()}
